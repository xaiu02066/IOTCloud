# 物模型定义文档

> 智慧农业环境监控平台 · 物模型（Thing Model）领域说明
> 适用范围：F3 物模型，对应 `product_properties` / `product_services` / `product_events` 三张关系表，以及 `products.thing_model` JSON 快照

---

## 1. 什么是"物模型"

**物模型**是对设备能力的结构化、数字化描述，是平台与设备之间"讲同一种语言"的基础。它把设备的：

- **属性（Property）**：设备可上报 / 可读取的状态量（如温度、湿度、开关状态）
- **服务（Service）**：平台可下发给设备的动作 / 调用（如开风机、设阈值）
- **事件（Event）**：设备主动上报、或平台侧触发的消息（如告警、上下线）

统一抽象出来，平台无需为每种设备写定制代码即可完成接入、存储、展示与控制。

本平台采用**双轨存储**：
- `products.thing_model`（JSON）：完整物模型快照，前端**一次加载**全量展示；
- `product_properties` / `product_services` / `product_events`（关系表）：把关键字段拆成行，便于**运维 SQL 查询**与管理界面**列表展示 / 检索**。

---

## 2. 属性（Property）

属性描述设备的状态量，分为**只读**（设备上报）与**读写**（平台可下发、设备本地存储）。

### 2.1 字段定义

| 字段 | 类型 | 说明 |
|------|------|------|
| `property_name` | string(128) | 属性名称 |
| `identifier` | string(64) | 属性标识符（同一产品内唯一），如 `air_temperature` |
| `data_type` | string(32) | 数据类型：`float` / `bool` / `int` / `string` |
| `unit` | string(16) | 单位，如 `°C` / `%RH` |
| `access_mode` | string(8) | `r`=只读，`rw`=读写 |
| `description` | string(255) | 说明 |

### 2.2 示例：智能环境测控仪的属性（env_ctrl）

| 序号 | 属性名称 | 标识符 | 类型 | 单位 | 读写 | 说明 |
|------|----------|--------|------|------|------|------|
| 1 | 空气温度 | `air_temperature` | float | °C | 只读 | 传感器采集上报 |
| 2 | 空气湿度 | `air_humidity` | float | %RH | 只读 | 传感器采集上报 |
| 3 | 土壤湿度 | `soil_humidity` | float | % | 只读 | 传感器采集上报 |
| 4 | 风机状态 | `fan_status` | bool | - | 只读 | true=运转，false=停止 |
| 5 | 温度告警阈值 | `temp_threshold` | float | °C | 读写 | 用户设定，设备本地存储 |
| 6 | 湿度告警阈值 | `humid_threshold` | float | % | 读写 | 用户设定，设备本地存储 |

> 只读型属性（温湿度等）的**实时数值**不存 MySQL，而是写入 **InfluxDB**（按 `measurement=产品, tag=设备, field=指标`）；读写型属性（两个阈值）的"期望值/当前值"可持久化在 `device_property_values` 表。

## 3. 服务（Service）

服务是平台下发给设备的**调用 / 动作**，通常带有输入参数与输出回执。

### 3.1 字段定义

| 字段 | 类型 | 说明 |
|------|------|------|
| `service_name` | string(128) | 服务名称 |
| `identifier` | string(64) | 服务标识符（同一产品内唯一），如 `set_fan` |
| `input_params` | JSON | 输入参数定义，如 `{"fan_state":"bool"}` |
| `output_params` | JSON | 输出参数定义，如 `{"result":"string"}` |
| `description` | string(255) | 说明 |

### 3.2 示例：智能环境测控仪的服务（env_ctrl）

| 序号 | 服务名称 | 标识符 | 输入参数 | 输出参数 | 说明 |
|------|----------|--------|----------|----------|------|
| 1 | 风机控制 | `set_fan` | `fan_state`(bool) | `result`(string) | 远程开 / 关风机 |
| 2 | 设置告警阈值 | `set_threshold` | `temp_max`(float)、`humid_min`(float) | `result`(string) | 批量修改告警线 |

---

## 4. 事件（Event）

事件是设备主动上报、或平台侧触发的消息，常作为**告警**与**状态变更**的载体。

### 4.1 字段定义

| 字段 | 类型 | 说明 |
|------|------|------|
| `event_name` | string(128) | 事件名称 |
| `identifier` | string(64) | 事件标识符（同一产品内唯一），如 `temp_alarm` |
| `trigger_position` | string(16) | 触发位置：`设备端` / `平台` |
| `output_params` | JSON | 输出参数定义 |
| `trigger_condition` | string(255) | 触发条件描述 |
| `description` | string(255) | 说明 |

### 4.2 示例：智能环境测控仪的事件（env_ctrl）

| 序号 | 事件名称 | 标识符 | 触发位置 | 输出参数 | 触发条件 |
|------|----------|--------|----------|----------|----------|
| 1 | 温度超限告警 | `temp_alarm` | 设备端 | `temperature`,`threshold`,`timestamp` | 温度 > 本地存储阈值 |
| 2 | 土壤湿度低告警 | `dry_alarm` | 设备端 | `humidity`,`threshold`,`timestamp` | 湿度 < 本地存储阈值 |
| 3 | 设备上线 | `online` | 平台 | `timestamp` | 设备连接成功 |
| 4 | 设备下线 | `offline` | 平台 | `timestamp` | 心跳超时 |

## 5. 完整物模型 JSON 结构（thing_model 字段示例）

`products.thing_model` 字段存如下结构的完整快照，供前端一次加载：

```json
{
  "product_key": "env_ctrl",
  "product_name": "智能环境测控仪",
  "description": "集数据采集与设备控制于一体的农业物联网终端",
  "protocol": "MQTT",
  "properties": [
    {"identifier":"air_temperature","property_name":"空气温度","data_type":"float","unit":"°C","access_mode":"r","description":"传感器采集上报"},
    {"identifier":"air_humidity","property_name":"空气湿度","data_type":"float","unit":"%RH","access_mode":"r","description":"传感器采集上报"},
    {"identifier":"soil_humidity","property_name":"土壤湿度","data_type":"float","unit":"%","access_mode":"r","description":"传感器采集上报"},
    {"identifier":"fan_status","property_name":"风机状态","data_type":"bool","unit":null,"access_mode":"r","description":"true=运转，false=停止"},
    {"identifier":"temp_threshold","property_name":"温度告警阈值","data_type":"float","unit":"°C","access_mode":"rw","description":"用户设定，设备本地存储"},
    {"identifier":"humid_threshold","property_name":"湿度告警阈值","data_type":"float","unit":"%","access_mode":"rw","description":"用户设定，设备本地存储"}
  ],
  "services": [
    {"identifier":"set_fan","service_name":"风机控制","input_params":{"fan_state":"bool"},"output_params":{"result":"string"},"description":"远程开/关风机"},
    {"identifier":"set_threshold","service_name":"设置告警阈值","input_params":{"temp_max":"float","humid_min":"float"},"output_params":{"result":"string"},"description":"批量修改告警线"}
  ],
  "events": [
    {"identifier":"temp_alarm","event_name":"温度超限告警","trigger_position":"设备端","output_params":{"temperature":"float","threshold":"float","timestamp":"string"},"trigger_condition":"温度 > 本地存储阈值"},
    {"identifier":"dry_alarm","event_name":"土壤湿度低告警","trigger_position":"设备端","output_params":{"humidity":"float","threshold":"float","timestamp":"string"},"trigger_condition":"湿度 < 本地存储阈值"},
    {"identifier":"online","event_name":"设备上线","trigger_position":"平台","output_params":{"timestamp":"string"},"trigger_condition":"设备连接成功"},
    {"identifier":"offline","event_name":"设备下线","trigger_position":"平台","output_params":{"timestamp":"string"},"trigger_condition":"心跳超时"}
  ]
}
```

## 6. 存储与代码位置

- 关系表：`product_properties` / `product_services` / `product_events`
- JSON 快照列：`products.thing_model`
- ORM 模型：`app/models/product.py` → `ProductProperty` / `ProductService` / `ProductEvent`
- 维护约定：修改物模型时应**同时维护关系表与 JSON 快照**，保证两者一致（后续可加校验 / 触发器）。
