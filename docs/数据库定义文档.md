# 数据库定义文档

> 智慧农业环境监控平台 · 元数据数据库
> 数据库：`iotcloud`（MySQL 8，字符集 `utf8mb4` / 排序 `utf8mb4_unicode_ci`）
> 建库脚本：`db/init_iotcloud.sql`（可重复执行，开头 `DROP DATABASE` 为破坏性重建，生产慎用）

---

## 1. 总体说明

本库存放**平台元数据**（产品、设备、物模型定义、告警规则等），不包含设备实时时序数据（温湿度等上报走 InfluxDB）。

- 元数据 MySQL 地址：`10.3.7.251:3306`，库名 `iotcloud`，账号 `root`
- 连接串示例：`mysql+pymysql://root:<pwd>@10.3.7.251:3306/iotcloud?charset=utf8mb4`
- 存储设计采用**双轨**：`products.thing_model`(JSON) 存完整物模型供前端一次加载；`product_properties`/`product_services`/`product_events` 关系表存关键字段供查询与列表展示。

## 3. 表结构明细

### 3.1 products（产品表）
| 列 | 类型 | 约束 | 说明 |
|----|------|------|------|
| `id` | INT UNSIGNED | PK, AUTO_INCREMENT | 产品 ID |
| `product_key` | VARCHAR(64) | UNIQUE, NOT NULL | 产品标识，如 `env_ctrl` |
| `product_name` | VARCHAR(128) | NOT NULL | 产品名称 |
| `description` | VARCHAR(255) | NULL | 产品定位 / 描述 |
| `protocol` | VARCHAR(32) | DEFAULT 'MQTT' | 接入协议 |
| `thing_model` | JSON | NULL | 完整物模型快照（前端一次加载） |
| `created_at` | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| `updated_at` | DATETIME | ON UPDATE CURRENT_TIMESTAMP | 更新时间 |

### 3.2 devices（设备表）
| 列 | 类型 | 约束 | 说明 |
|----|------|------|------|
| `id` | INT UNSIGNED | PK | 设备 ID |
| `device_key` | VARCHAR(64) | UNIQUE, NOT NULL | 设备标识 / DeviceName |
| `device_name` | VARCHAR(128) | NOT NULL | 设备名称 |
| `product_id` | INT UNSIGNED | FK→products(id) | 所属产品 |
| `status` | TINYINT | DEFAULT 0 | 0=离线, 1=在线 |
| `created_at` | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| `last_online` | DATETIME | NULL | 最近上线时间 |

### 3.3 product_properties（物模型-属性）
| 列 | 类型 | 约束 | 说明 |
|----|------|------|------|
| `id` | INT UNSIGNED | PK | - |
| `product_id` | INT UNSIGNED | FK→products(id) | 所属产品 |
| `property_name` | VARCHAR(128) | NOT NULL | 属性名称 |
| `identifier` | VARCHAR(64) | NOT NULL | 属性标识符（同产品唯一） |
| `data_type` | VARCHAR(32) | NOT NULL | float/bool/int/string |
| `unit` | VARCHAR(16) | NULL | 单位 |
| `access_mode` | VARCHAR(8) | DEFAULT 'r' | r=只读, rw=读写 |
| `description` | VARCHAR(255) | NULL | 说明 |

> 唯一索引：`(product_id, identifier)`

### 3.4 product_services（物模型-服务）
| 列 | 类型 | 约束 | 说明 |
|----|------|------|------|
| `id` | INT UNSIGNED | PK | - |
| `product_id` | INT UNSIGNED | FK→products(id) | 所属产品 |
| `service_name` | VARCHAR(128) | NOT NULL | 服务名称 |
| `identifier` | VARCHAR(64) | NOT NULL | 服务标识符（同产品唯一） |
| `input_params` | JSON | NULL | 输入参数定义 |
| `output_params` | JSON | NULL | 输出参数定义 |
| `description` | VARCHAR(255) | NULL | 说明 |

### 3.5 product_events（物模型-事件）
| 列 | 类型 | 约束 | 说明 |
|----|------|------|------|
| `id` | INT UNSIGNED | PK | - |
| `product_id` | INT UNSIGNED | FK→products(id) | 所属产品 |
| `event_name` | VARCHAR(128) | NOT NULL | 事件名称 |
| `identifier` | VARCHAR(64) | NOT NULL | 事件标识符（同产品唯一） |
| `trigger_position` | VARCHAR(16) | NULL | 设备端 / 平台 |
| `output_params` | JSON | NULL | 输出参数定义 |
| `trigger_condition` | VARCHAR(255) | NULL | 触发条件 |
| `description` | VARCHAR(255) | NULL | 说明 |

### 3.6 device_property_values（设备读写属性值）
| 列 | 类型 | 约束 | 说明 |
|----|------|------|------|
| `id` | INT UNSIGNED | PK | - |
| `device_id` | INT UNSIGNED | FK→devices(id) | 所属设备 |
| `property_identifier` | VARCHAR(64) | NOT NULL | 属性标识符 |
| `value` | TEXT | NULL | 当前 / 期望值 |
| `updated_at` | DATETIME | ON UPDATE CURRENT_TIMESTAMP | 更新时间 |

> 唯一索引：`(device_id, property_identifier)`

### 3.7 device_commands（设备指令下发/回执）
| 列 | 类型 | 约束 | 说明 |
|----|------|------|------|
| `id` | INT UNSIGNED | PK | - |
| `device_id` | INT UNSIGNED | FK→devices(id) | 所属设备 |
| `service_identifier` | VARCHAR(64) | NOT NULL | 服务标识符 |
| `command_id` | VARCHAR(64) | NULL | 指令关联 ID（messageId） |
| `input_params` | JSON | NULL | 下发参数 |
| `status` | VARCHAR(16) | DEFAULT 'pending' | pending/success/failed/timeout |
| `result` | VARCHAR(255) | NULL | 回执结果 |
| `created_at` | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| `finished_at` | DATETIME | NULL | 完成时间 |

### 3.8 device_events（设备事件/告警记录）
| 列 | 类型 | 约束 | 说明 |
|----|------|------|------|
| `id` | INT UNSIGNED | PK | - |
| `device_id` | INT UNSIGNED | FK→devices(id) | 所属设备 |
| `event_identifier` | VARCHAR(64) | NOT NULL | 事件标识符 |
| `output_data` | JSON | NULL | 输出参数 |
| `created_at` | DATETIME | DEFAULT CURRENT_TIMESTAMP | 触发时间 |

### 3.9 alarm_rules（告警规则）
| 列 | 类型 | 约束 | 说明 |
|----|------|------|------|
| `id` | INT UNSIGNED | PK | - |
| `product_id` | INT UNSIGNED | FK→products(id) | 所属产品 |
| `device_id` | INT UNSIGNED | FK→devices(id), NULL | 为空=产品级规则，适用该产品所有设备 |
| `rule_name` | VARCHAR(128) | NOT NULL | 规则名称 |
| `metric` | VARCHAR(64) | NOT NULL | 监测属性标识符，如 `air_temperature` |
| `operator` | VARCHAR(8) | NOT NULL | >, <, >=, <=, ==, != |
| `threshold` | DOUBLE | NOT NULL | 阈值 |
| `level` | VARCHAR(16) | DEFAULT 'warning' | warning/critical |
| `enabled` | TINYINT | DEFAULT 1 | 0=禁用, 1=启用 |
| `description` | VARCHAR(255) | NULL | 说明 |
| `created_at` | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| `updated_at` | DATETIME | ON UPDATE CURRENT_TIMESTAMP | 更新时间 |

## 4. 外键关系

```
products (1) ──< (N) product_properties
products (1) ──< (N) product_services
products (1) ──< (N) product_events
products (1) ──< (N) devices
products (1) ──< (N) alarm_rules
devices  (1) ──< (N) device_property_values
devices  (1) ──< (N) device_commands
devices  (1) ──< (N) device_events
devices  (1) ──< (N) alarm_rules (device_id 可空，空=产品级)
```

> 注：关系表外键未启用数据库级 `ON DELETE CASCADE`，由应用层（SQLAlchemy `cascade="all, delete-orphan"`）在删除产品时级联清理其子定义；`alarm_rules.device_id` 为可选，用于把规则精确到单台设备。

## 5. 种子数据

执行 `db/init_iotcloud.sql` 后，自动写入：

- 6 个属性、`2` 个服务、`4` 个事件（见《物模型定义文档》）
